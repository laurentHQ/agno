# How to Save Agent Responses to Markdown Reports

This guide shows you different ways to capture `agent.print_response()` output and save it as markdown files in the `reports/` folder.

## 🚀 Quick Start

### Method 1: Simplest Way (Recommended)
```python
from report_utils import quick_news_report

# One-liner to generate and save a report
filepath = quick_news_report("What are today's top tech stories?")
print(f"Report saved to: {filepath}")
```

### Method 2: Using Agent Directly
```python
from multisource_news_agent import create_enhanced_news_agent
from report_utils import save_agent_response_to_md

agent = create_enhanced_news_agent()
filepath = save_agent_response_to_md(
    agent=agent,
    query="Give me the latest AI news",
    filename="ai_news_report",
    title="AI News Update"
)
```

## 📋 Available Methods

### 1. Quick News Report
**File:** `report_utils.py` → `quick_news_report()`

```python
from report_utils import quick_news_report

# Basic usage
filepath = quick_news_report("Your query here")

# With custom filename
filepath = quick_news_report(
    query="Latest cryptocurrency news",
    filename="crypto_update",
    agent_type="enhanced"  # or "basic"
)
```

**Features:**
- ✅ Minimal setup required
- ✅ Auto-generates filename if not provided
- ✅ Choose between basic/enhanced agent
- ✅ Perfect for quick reports

### 2. Batch Reports
**File:** `report_utils.py` → `batch_news_reports()`

```python
from report_utils import batch_news_reports

queries = [
    "What's happening in tech today?",
    "Latest financial market news",
    "Startup funding announcements"
]

filepaths = batch_news_reports(
    queries=queries,
    base_filename="daily_briefing"
)

print(f"Generated {len(filepaths)} reports")
```

**Features:**
- ✅ Multiple reports at once
- ✅ Numbered automatically
- ✅ Consistent naming scheme
- ✅ Perfect for daily briefings

### 3. Custom Reporter Class
**File:** `news_reporter.py` → `NewsReporter`

```python
from news_reporter import NewsReporter
from multisource_news_agent import create_enhanced_news_agent

reporter = NewsReporter()
agent = create_enhanced_news_agent()

# Single report
filepath = reporter.generate_report(
    agent=agent,
    query="AI developments today",
    filename="ai_report",
    title="AI Technology Report"
)

# Daily digest (comprehensive)
filepath = reporter.generate_daily_digest(agent)
```

**Features:**
- ✅ Full control over formatting
- ✅ Multiple report types
- ✅ Daily digest generation
- ✅ Custom markdown formatting

### 4. Direct Capture Method
**File:** `save_reports_example.py` → `method_1_direct_save()`

```python
from multisource_news_agent import create_enhanced_news_agent
from datetime import datetime
import os

agent = create_enhanced_news_agent()
response = agent.run("Your query here")

# Custom markdown formatting
markdown_content = f"""# My Custom Report

**Generated:** {datetime.now().strftime("%Y-%m-%d %H:%M:%S")}

{response.content}

*Generated by Agno*
"""

# Save to file
os.makedirs("reports", exist_ok=True)
filename = f"reports/custom_report_{datetime.now().strftime('%Y%m%d_%H%M%S')}.md"
with open(filename, 'w', encoding='utf-8') as f:
    f.write(markdown_content)
```

**Features:**
- ✅ Full customization
- ✅ Custom markdown structure
- ✅ Direct file operations
- ✅ Maximum flexibility

### Example 4: Custom Formatted Report
```python
from multisource_news_agent import create_enhanced_news_agent
from datetime import datetime

agent = create_enhanced_news_agent()

# Generate multiple sections
sections = [
    ("Breaking News", "What are today's breaking news headlines?"),
    ("Technology", "Latest tech developments and AI news"),
    ("Business", "Major business and startup announcements"),
    ("Markets", "Financial market movements and analysis")
]

report = f"""# Comprehensive Daily News Report

**Date:** {datetime.now().strftime("%B %d, %Y")}
**Generated:** {datetime.now().strftime("%H:%M:%S")}

"""

for title, query in sections:
    response = agent.run(query)
    report += f"""## {title}

{response.content}

---

"""

# Save custom report
filename = f"reports/comprehensive_daily_{datetime.now().strftime('%Y%m%d')}.md"
with open(filename, 'w') as f:
    f.write(report)
```

## 📁 File Organization

All reports are saved in the `reports/` directory with the following structure:

```
reports/
├── daily_tech_news_20250106_143022.md
├── ai_report_20250106_143045.md
├── market_analysis_20250106_143108.md
├── daily_briefing_01_20250106_143130.md
├── daily_briefing_02_20250106_143152.md
└── comprehensive_daily_20250106.md
```

**Naming Conventions:**
- `{custom_name}_{timestamp}.md` - Single reports
- `{base_name}_{number}_{timestamp}.md` - Batch reports
- `daily_digest_{date}.md` - Daily digests
- Auto-generated names use query keywords

## 💡 Tips and Best Practices

### 1. Filename Best Practices
```python
# Good: Descriptive and timestamp

    "AI developments",

)

filepath = quick_news_report(
    "AI developments",
    filename=f"ai_developments_{date_str}"
)
```

### 2. Query Optimization

### 3. Batch Processing

    "AI and machine learning updates",
    "Startup funding and acquisitions",
    "Cryptocurrency and blockchain news"

### 4. Error Recovery
```python
def safe_report_generation(queries, base_filename):
    successful_reports = []
    failed_queries = []

    for i, query in enumerate(queries):
        try:
            filepath = quick_news_report(query, f"{base_filename}_{i:02d}")
            successful_reports.append(filepath)
        except Exception as e:
            failed_queries.append((query, str(e)))
            print(f"Failed to generate report for: {query}")

    return successful_reports, failed_queries
```

## 🔄 Automation Ideas

### 1. Scheduled Reports
```python
import schedule
import time

def generate_morning_briefing():
    filepath = quick_news_report(
        "What are today's most important news stories across tech, business, and global affairs?",
        filename=f"morning_briefing_{datetime.now().strftime('%Y%m%d')}"
    )
    print(f"Morning briefing generated: {filepath}")

# Schedule for 8 AM daily
schedule.every().day.at("08:00").do(generate_morning_briefing)

while True:
    schedule.run_pending()
    time.sleep(60)
```

### 2. Webhook Integration
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/generate-report', methods=['POST'])
def generate_report_webhook():
    data = request.json
    query = data.get('query', 'Latest news')
    filename = data.get('filename')

    try:
        filepath = quick_news_report(query, filename)
        return jsonify({"success": True, "filepath": str(filepath)})
    except Exception as e:
        return jsonify({"success": False, "error": str(e)})

if __name__ == '__main__':
    app.run(port=5000)
```
